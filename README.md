A responsive black-and-gold static website for GitHub Pages. It uses plain HTML, CSS and JavaScript; no build tools or paid hosting are required.

## Before publishing

1. Open `script.js`.
2. Replace `PASTE_YOUR_GOOGLE_FORM_URL_HERE` with the **published Google Forms URL** (usually starts with `https://docs.google.com/forms/`).
   - The value supplied as the application URL was `+2347062668393`, which is a phone number, not a form URL.
   - WhatsApp is already configured as `https://wa.me/2347062668393`.
3. Review the business name, descriptions, proposed tiers and legal wording.
4. Do not publish claims of returns, client testimonials, regulatory approval or guarantees unless independently verified and legally approved.

## Publish free with GitHub Pages

1. Sign in at https://github.com and create a new **public** repository, e.g. `invesec-website`.
2. Upload the contents of this folder (make sure `index.html` is at the repository root, not inside another folder).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your site URL will look like `https://YOUR-USERNAME.github.io/invesec-website/`.
